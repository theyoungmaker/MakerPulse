# MakerPulse — Glossary

- **Settings page**: the HTML page the MakerPulse device itself serves over WiFi (via `WebServer` on port 80, built in `handleRoot()`/`handleSave()` in `src/settings_server.cpp`). This is where a user enters their own LTA AccountKey, bus stops, nickname, colors, timers, location, etc. It only exists once the device is already on a network and running.
- **Setup site / flashing site**: the separate static website at `docs/` (deployed via GitHub Pages, e.g. `theyoungmaker.github.io/MakerPulse`), built on [ESP Web Tools](https://esphome.github.io/esp-web-tools/). This is where a brand-new device gets firmware flashed over USB/WebSerial, and where Wi-Fi is provisioned afterward via the Improv Wi-Fi serial protocol. It exists independently of any MakerPulse device being powered on or networked.
- **AccountKey**: the credential LTA DataMall requires per request. MakerPulse ships with a built-in shared fallback (`LTA_FALLBACK_API_KEY`) so bus arrivals work out of the box; a user's own key, once entered on the settings page, always takes priority over the fallback. The fallback value itself is never written to Preferences and never shown on the settings page.
- **Accent color** / **Text color**: the two single-swatch colors on the settings page. Each offers a fixed set of named presets (e.g. "cyan", "mint") plus one trailing custom swatch that opens the browser's native RGB color picker, letting a user pick any color instead of only a preset. Distinct from **Theme** below.
- **Theme**: the settings-page control for the device's background/panel palette (background, panel, panel-alt, stroke, etc. together). Unlike Accent/Text, a Theme is a curated, multi-color set rather than one color, so it is preset-only — it has no custom-picker option.
